Decisões tomadas

TemaDecisão
StackReact + TypeScript + Vite no front (tokens em variáveis CSS, sem Tailwind), API em Node + TypeScript (Fastify), testes com Vitest, Playwright e axe, verificação de segredos com gitleaks.
Fonte da verdadePostgreSQL próprio. O Excel passa a ser só importação e exportação.
HospedagemNenhuma no Azure por enquanto. Desenvolvimento e testes locais, com até cerca de 1.000 arquivos. A TI avalia o Azure depois de testes bem-sucedidos.
RevisõesAprovado é estado final, sem "Reabrir". Uma revisão é um documento novo com vínculo ao documento de origem. O código é único na combinação código + revisão.
ReativaçãoUm cancelado volta ao status que tinha antes do cancelamento, pela mesma regra em todos os pontos da tela (resolve o P-17).
TelasSem versão específica para celular. O sistema é responsivo para computador e tablet, a partir de 768px, sem rolagem horizontal da página.
CoresSeguir o arquivo do Figma, mantendo o contraste mínimo de 4,5:1 (texto do item ativo da barra lateral mais escuro no tema claro).
MigraçãoA importação da base antiga, preservando os IDs, entra na Fundação.
OfflineRascunho local com reenvio automático, como fatia própria.

Regras que valem para todas as fatias

Nada decorativoUm link, botão ou menu só aparece quando o destino ou a ação já funciona de verdade.
Segurança dentro do escopoNenhum segredo no código, dado exibido sempre tratado, permissão verificada no servidor.
Decisão antes do códigoRegistro em docs/decisoes/ e uma linha no CHANGELOG na data da mudança.
Revisão e validaçãoO agente de QA revisa cada fatia e o Eric valida antes da próxima começar.
