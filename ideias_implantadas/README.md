# Ideias implantadas

Ideias do DocFlow que já foram implementadas pelo Antigravity e validadas pelo Eric. O fluxo completo está em [`ideias/README.md`](../ideias/README.md).

A estrutura espelha a da pasta `ideias/`. Uma ideia implantada vai para a mesma pasta de tipo, com o mesmo nome:

```
ideias_implantadas/
  modelos/
    modelo_design/
    modelo_funcao/
    modelo_problema/
```

> **Ao mover um arquivo para cá:** mude o status para **Implantada**, preencha a seção "Resultado da implantação" no fim do arquivo e adicione uma linha na tabela abaixo.
